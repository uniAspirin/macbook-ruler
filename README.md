# MacBook Ruler

当我们在 CSS 中写下 width: 1cm，能不能让它在屏幕上真的就是一厘米？

通常不能保证。屏幕上的 CSS 绝对单位采用固定的换算关系，却不一定对应真实的物理长度。要把屏幕当作尺子，还需要根据显示参数进行校准。

有趣的是，在默认显示设置和浏览器 100% 缩放下，我手里的 14 英寸 MacBook Pro 上，500 CSS px 恰好约为 10.00 cm。这个巧合成了项目的起点。

MacBook Ruler 根据屏幕的物理分辨率、逻辑分辨率和对角线尺寸，计算 CSS px 与实际长度的对应关系，让 MacBook 和其他显示器都能成为一把相对准确的尺子。

使用 React、Vite 和 Tailwind CSS 构建。

## 本地运行

```bash
npm install
npm run dev
```

## 使用说明

选择与当前屏幕和显示设置匹配的预设，或手动输入参数。浏览器缩放请保持 100%，测量结果建议用实体尺核对。
